# 程度副詞互動教學
依《程度副詞.docx》建立的繁體中文教材網站，使用 GitHub Pages 發布。

## 內容
程度副詞語法比較、重新適應的第一個月閱讀、7 題閱讀理解、5 題選詞練習、4 張教材圖片看圖說話、80–100 字寫作自查。

## 使用與維護
純 HTML / CSS / JavaScript，無須安裝套件。以 index.html 為首頁，所有路徑為相對路徑。
作答不傳送至伺服器、不保存到瀏覽器儲存空間。重新整理前請複製需保留的文字。

## 教材編修
修正「念書所已經」筆誤。程度分組補充語氣與語境差異，不把「最」與「完全」當作線性強度排名。
選詞第 1 題明確指定高程度，說明「很」亦可自然使用。第 2 題增加未完全適應的語境。第 3、5 題補齊「太＋形容詞＋了」句型。
閱讀參考答案與語法解說為教學改編；圖片取自使用者提供的教材。
原始 DOCX 未上傳；公開網站只包含課堂所需內容與壓縮圖片。
